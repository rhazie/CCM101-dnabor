# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basic environment and tools used in cloud computing. The mission focuses on working with a Linux environment through KillerCoda and creating a professional Cloud Computing Portfolio using GitHub.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

- Accessed an Ubuntu 24.04.4 LTS environment using KillerCoda.
- Created the required Linux user `dnabor`.
- Verified the username, working directory, and hostname.
- Gathered Linux distribution, kernel, CPU, memory, and disk information.
- Created Markdown files and organized the laboratory directory structure.
- Created the public GitHub repository `CCM101-dnabor`.

## Linux Commands Used

- `whoami` – displayed the current username.
- `pwd` – displayed the current working directory.
- `hostname` – displayed the system hostname.
- `cat /etc/os-release` – displayed Linux distribution information.
- `uname -r` – displayed the kernel version.
- `lscpu` – displayed CPU information.
- `free -h` – displayed memory information.
- `df -h` – displayed disk space information.
- `mkdir` – created directories.
- `touch` – created files.
- `cp` – copied files.
- `find` – displayed files and directories.
- `nano` – edited Markdown files.

## Skills Learned

- Basic Linux command-line navigation.
- Linux system information gathering.
- File and directory organization.
- Markdown documentation.
- Basic GitHub repository organization.
- Cloud-based Linux environment usage.

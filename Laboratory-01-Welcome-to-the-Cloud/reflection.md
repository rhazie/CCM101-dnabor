# Reflection

This laboratory activity gave me practical experience working with a cloud-based Linux environment through KillerCoda. I learned how to create and use a Linux user, navigate the Linux environment, and collect basic system information.

I also learned how to organize files and directories using Linux commands and document my work using Markdown. Creating the GitHub repository helped me understand how a Cloud Computing Portfolio can be organized and maintained throughout the semester.

Overall, this activity helped me become more comfortable with the Linux command line and introduced me to the documentation and version-control practices that will be useful in future cloud computing laboratory activities.

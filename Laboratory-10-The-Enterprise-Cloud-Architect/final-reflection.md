# Final Reflection

Throughout the progression of our laboratory activities, my technical capabilities grew substantially. In our early missions, I focused on learning fundamental Linux command-line operations, navigating directories, and managing file permissions. Transitioning from those basic tasks to Mission 10 required a complete shift in perspective—moving from an individual user mindset to that of an Enterprise Cloud Architect responsible for system reliability, security hardening, and disaster recovery.

Deploying a multi-tier architecture using Docker Compose taught me the critical importance of container isolation and persistent storage. By separating the LinuxServer BookStack application container from the MySQL 8.0 database container onto an internal bridge network, I ensured that sensitive database ports remained entirely hidden from external threats. Furthermore, configuring persistent volumes (`db_data` and `bookstack_data`) guaranteed that corporate documentation and transactional records survived container reboots and software updates without data loss.

Implementing the Uncomplicated Firewall (UFW) and automating disaster recovery backups reinforced my understanding of proactive server security. Enforcing a strict default-deny incoming policy while selectively allowing administrative SSH access and HTTP web traffic demonstrated how to minimize attack surfaces. Additionally, combining custom Bash scripts with automated cron jobs highlighted how system automation eliminates human error and safeguards enterprise data against unforeseen failures. This capstone experience successfully synthesized my technical skills across web application deployment, network security, and cloud infrastructure management.

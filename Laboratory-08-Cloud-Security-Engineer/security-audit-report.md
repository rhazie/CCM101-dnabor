# Security Audit Report

## Principle of Least Privilege (PoLP)
The Principle of Least Privilege means giving cloud user accounts only the permissions they need to perform their tasks. This is important because if an account is stolen, an attacker with limited permissions can do less damage than one with full administrator access.

## Attack Surface
The attack surface of a virtual machine includes all the possible entry points an attacker could use to access it. These include open ports and running services such as SSH and web servers, so disabling unnecessary ports and services helps reduce security risks.

## Default Deny Policy
A default deny policy blocks all access unless it is explicitly allowed. It is safer than blocking specific hackers individually because it can also block unknown attackers who have not yet been identified.

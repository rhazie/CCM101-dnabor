# Laboratory 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory was about understanding the basic components that make up cloud infrastructure. I used a Linux virtual machine in KillerCoda to examine compute, storage, networking, and operating system resources, then documented the results and created a simple cloud infrastructure diagram.

## Objectives

* Explain the major components of cloud infrastructure
* Investigate hardware and software resources in a Linux environment
* Differentiate compute, storage, networking, and identity resources
* Interpret the relationship between cloud infrastructure components
* Create professional technical documentation using Markdown
* Continue building a structured GitHub Cloud Computing Portfolio

## Cloud Infrastructure Components

See [cloud-components.md](./cloud-components.md) for detailed breakdown of Compute, Storage, Networking, and Operating System.

## Tools Used

* KillerCoda Playground (Ubuntu 24.04 environment)
* Linux terminal commands
* draw.io (architecture diagram)
* GitHub (portfolio and version control)
* Markdown

## Linux Commands Executed

| Command               | Purpose                                     |
| --------------------- | ------------------------------------------- |
| `cat /etc/os-release` | Check operating system                      |
| `uname -r`            | Check kernel version                        |
| `lscpu`               | Check CPU model and core count              |
| `free -h`             | Check total RAM                             |
| `df -h`               | Check disk capacity and mounted filesystems |
| `hostname`            | Check server hostname                       |
| `ip a`                | Check IP address                            |

## Skills Learned

In this laboratory, I learned how to use basic Linux commands to inspect the resources of a virtual machine. I learned how to identify the operating system, kernel, CPU, RAM, disk, hostname, and network interface. I also learned how these resources relate to cloud infrastructure and how similar services are provided by AWS, Microsoft Azure, and Google Cloud. Finally, I practiced creating a cloud infrastructure diagram and organizing my work using Markdown and GitHub.

## Challenges Encountered

One challenge I encountered was understanding the information displayed by some Linux commands, especially the different values shown for CPU, memory, storage, and network interfaces. I also needed to understand how the resources I saw in the virtual machine relate to actual cloud services. Another challenge was organizing the documentation and creating the infrastructure diagram, but practicing with Markdown and draw.io made the process easier.

# Cloud Provider Comparison

## Core Cloud Services

| Component                        | AWS                                  | Microsoft Azure        | Google Cloud Platform       |
| -------------------------------- | ------------------------------------ | ---------------------- | --------------------------- |
| **Compute**                      | EC2 (Elastic Compute Cloud)          | Virtual Machines       | Compute Engine              |
| **Storage**                      | S3 (Object), EBS (Block), EFS (File) | Blob Storage           | Cloud Storage               |
| **Networking**                   | VPC (Virtual Private Cloud)          | VNet (Virtual Network) | VPC (Virtual Private Cloud) |
| **Identity & Access Management** | AWS IAM                              | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which provider offers the broadest range of services?

I think **AWS** offers the broadest range of cloud services among the three providers. It has a very large selection of services for different purposes, including computing, storage, networking, databases, security, analytics, IoT, and other specialized workloads.

### 2. Which provider is best for a Microsoft-centric organization?

**Microsoft Azure** is a strong choice for an organization that already uses many Microsoft products and technologies. Azure works closely with services such as Windows Server, Microsoft 365, Active Directory/Entra ID, and other Microsoft enterprise tools, making integration easier.

### 3. Which provider is best known for AI/ML and Kubernetes?

**Google Cloud Platform (GCP)** is well known for artificial intelligence, machine learning, and Kubernetes. Google created Kubernetes and has extensive experience in AI and machine learning, so GCP provides strong services and tools for these types of workloads.

### 4. What are the similarities between AWS, Azure, and GCP?

All three providers offer similar fundamental cloud services, including compute, storage, networking, and identity and access management. They also provide global infrastructure and support usage-based or pay-as-you-go pricing, allowing organizations to use resources without owning the physical infrastructure themselves.

## Summary

AWS, Microsoft Azure, and Google Cloud Platform provide many of the same fundamental cloud capabilities, but each has areas where it is particularly strong. AWS is known for its large variety of services, Azure is a natural choice for Microsoft-focused organizations, and GCP is especially recognized for Kubernetes, AI, and machine learning.

# Mission Reflection

This laboratory helped me understand that cloud infrastructure is made up of different components that work together to provide services. Before doing this activity, I mostly thought of cloud computing as simply using servers through the internet. After exploring the Linux environment and creating an infrastructure blueprint, I now have a better understanding of what happens behind cloud services.

**1. Which cloud infrastructure component do you think is the most important? Why?**

I think **compute** is the most important component because it provides the processing resources needed to run applications and workloads. Without compute resources such as CPU and RAM, applications would not be able to execute. However, compute still needs networking and storage to communicate with users and access data, so all components must work together.

**2. How does Linux support cloud computing?**

Linux supports cloud computing by providing a stable and flexible operating system for servers and virtual machines. It also provides many powerful command-line tools that administrators can use to monitor and manage system resources. Linux is widely used in cloud environments because it is efficient, customizable, and works well with technologies such as containers and virtualization.

**3. Why is technical documentation important before deploying infrastructure?**

Technical documentation is important because it provides a clear plan for how the infrastructure should be organized and configured. It helps prevent mistakes, makes troubleshooting easier, and allows other people to understand and maintain the system. Creating the blueprint before deployment also helps identify missing components or possible problems.

**4. What new skills did you learn during this laboratory activity?**

I learned how to use Linux commands such as `lscpu`, `free -h`, `df -h`, and `ip a` to inspect system resources. I also learned how cloud providers organize compute, storage, networking, and identity services. In addition, I practiced creating technical documentation with Markdown and designing a cloud infrastructure diagram using draw.io.

**5. How has your GitHub portfolio improved after completing this mission?**

My GitHub portfolio became more organized and useful because I added documentation, system information, cloud component explanations, and an infrastructure diagram. It now shows not only the results of my laboratory work but also the practical skills I developed while completing the mission. This gives me a better foundation for adding more cloud computing projects in future laboratories.

# Laboratory 05 - Cloud Data Engineer

## Mission Overview

As part of the Cloud Data Engineering Team at CloudNova Technologies, this lab involved deploying a proof-of-concept Object Storage environment for a client's photo-sharing application. Using Docker, an S3-compatible object storage server (MinIO) was deployed, a secure bucket named `client-photos` was created, and a test file was uploaded to confirm the system works.

## Objectives

- Differentiate between Block, File, and Object Storage
- Deploy an S3-compatible Object Storage server (MinIO) using Docker
- Access a cloud service via a web interface using port forwarding
- Create a storage bucket and upload objects (files) to the cloud
- Document cloud storage operations using Markdown
- Continue expanding a professional GitHub Cloud Computing Portfolio

## Tools Used

- Docker
- MinIO (`pgsty/minio` mirror image)
- KillerCoda Ubuntu Playground
- GitHub
- Markdown

## Skills Learned

- Deploying a containerized object storage service using environment variables in Docker
- Understanding the differences between Block, File, and Object Storage
- Accessing and managing a cloud service through a web console via port forwarding
- Creating storage buckets and uploading objects to an S3-compatible server
- Troubleshooting Docker image pull/registry connectivity issues
- Documenting technical cloud configurations clearly using Markdown

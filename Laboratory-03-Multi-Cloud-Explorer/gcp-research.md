# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides services for computing, storage, databases, networking, data analytics, artificial intelligence, machine learning, containers, and application development. Google Cloud allows organizations to build and operate applications using Google's global infrastructure.

## Global Infrastructure

Google Cloud organizes its infrastructure into **Regions** and **Zones**. A Region is a geographic area containing multiple Zones, while Zones provide isolated locations for deploying workloads. Google Cloud's global network connects infrastructure around the world and is designed to support high performance, reliability, and low-latency applications.

As of August 2026, Google Cloud lists **43 regions and 130 zones** across its global infrastructure.

## Cloud Management Console

The **Google Cloud Console** is a web-based interface used to create, manage, monitor, and configure Google Cloud resources. It provides access to services, projects, resources, billing, monitoring, and other cloud-management tools. Google Cloud resources are organized within projects, which also contain settings, permissions, and metadata.

## Four (4) Core Services

1. **Compute Engine** – Provides virtual machines that run on Google's infrastructure for websites, applications, databases, and other workloads.
2. **Cloud Storage** – Provides scalable object storage for files, backups, media, and application data.
3. **Cloud SQL** – Provides a fully managed relational database service for supported database systems such as MySQL, PostgreSQL, and SQL Server.
4. **BigQuery** – Provides a cloud data warehouse and analytics platform for analyzing large amounts of data.

## Three (3) Advantages

1. **Global Network** – Google operates a large global network designed for fast and reliable connectivity.
2. **Strong Data and AI Capabilities** – Google Cloud provides powerful services for analytics, machine learning, and artificial intelligence.
3. **Scalable Infrastructure** – Organizations can scale computing, storage, databases, and other resources according to their workload requirements.

## Typical Enterprise Use Cases

- Hosting websites, APIs, and business applications.
- Large-scale data analytics and business intelligence.
- Artificial intelligence and machine learning projects.
- Running virtual machines and containerized applications.
- Storing company data, backups, and media.
- Modernizing applications and building cloud-native systems.

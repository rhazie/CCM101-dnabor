## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers the broadest range of cloud services among the three major providers. It has a very large portfolio covering computing, storage, databases, networking, security, analytics, machine learning, serverless computing, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

**Microsoft Azure** provides the strongest integration with Microsoft technologies. It works closely with products and services such as Windows Server, Microsoft SQL Server, Microsoft Entra ID, Microsoft 365, and other Microsoft enterprise technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP)** is particularly strong in artificial intelligence, data analytics, and Kubernetes. Google created Kubernetes and continues to provide strong Kubernetes and AI capabilities through services such as Google Kubernetes Engine (GKE) and Vertex AI.

### 4. Which cloud platform would you personally choose and why?

**I would personally choose AWS** because it provides a broad range of services and is useful for learning different areas of cloud computing. Its services such as EC2, S3, VPC, and IAM provide a strong foundation for learning cloud infrastructure and deploying applications.

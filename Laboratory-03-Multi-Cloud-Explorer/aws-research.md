# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform from Amazon that provides a large collection of on-demand services for computing, storage, databases, networking, security, analytics, and application development. Organizations can use AWS resources over the internet without having to purchase and maintain all of the physical infrastructure themselves.

## Global Infrastructure

AWS operates a worldwide cloud infrastructure organized into **Regions** and **Availability Zones (AZs)**. Regions are separate geographic areas, while Availability Zones are isolated locations within Regions that help improve application availability and resilience. AWS provides infrastructure that allows organizations to deploy applications close to their users and distribute workloads for reliability.

## Cloud Management Console

The **AWS Management Console** is a web-based interface used to access and manage AWS services. It provides centralized access to service consoles, resource management, monitoring, billing, notifications, and other cloud-management functions. Users can also search for services and use AWS CloudShell from the console.

## Four (4) Core Services

1. **Amazon EC2 (Elastic Compute Cloud)** – Provides virtual servers that can be used to run applications and workloads in the cloud.
2. **Amazon S3 (Simple Storage Service)** – Provides scalable object storage for files, backups, data, and application content.
3. **Amazon RDS (Relational Database Service)** – Provides managed relational databases such as MySQL, PostgreSQL, and other supported database engines.
4. **AWS Lambda** – Runs application code without requiring users to manage servers. It is commonly used for event-driven and serverless applications.

## Three (3) Advantages

1. **Scalability** – AWS resources can be increased or decreased according to workload requirements.
2. **Global Availability** – Its worldwide infrastructure allows organizations to deploy applications in different geographic locations.
3. **Large Service Portfolio** – AWS provides many services for computing, storage, databases, networking, security, analytics, and application development.

## Typical Enterprise Use Cases

- Hosting websites, web applications, and business applications.
- Storing company files, backups, and large datasets.
- Running databases and enterprise workloads.
- Building serverless applications and automated business processes.
- Disaster recovery and business continuity.
- Data analytics, machine learning, and artificial intelligence.

# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, databases, networking, security, analytics, artificial intelligence, application development, and hybrid cloud environments. Azure can be used to build, deploy, and manage applications and infrastructure through Microsoft's global cloud network.

## Global Infrastructure

Azure has a global infrastructure made up of geographic areas, Regions, and datacenters. Microsoft provides many Azure Regions around the world so organizations can select locations based on factors such as latency, data residency, compliance, and availability. Azure's global infrastructure is designed to support scalable and resilient cloud applications.

## Cloud Management Console

The **Azure portal** is a web-based, unified management console for creating and managing Azure resources. Through the portal, users can create virtual machines, databases, web applications, and other resources. It also provides dashboards, monitoring, resource management, subscription management, and cost-management features.

## Four (4) Core Services

1. **Azure Virtual Machines** – Provides scalable virtual machines for running Windows or Linux workloads in the cloud.
2. **Azure Blob Storage** – Provides scalable object storage for documents, media, backups, and other unstructured data.
3. **Azure SQL Database** – Provides a managed relational database service based on Microsoft SQL technologies.
4. **Azure Virtual Network (VNet)** – Provides private networking for Azure resources and allows organizations to control network connectivity and security.

## Three (3) Advantages

1. **Strong Microsoft Integration** – Azure works well with Microsoft technologies such as Windows Server, Microsoft SQL Server, Active Directory, and Microsoft 365.
2. **Global Infrastructure** – Azure provides many geographic locations that support low latency, availability, and data-residency requirements.
3. **Hybrid Cloud Support** – Azure provides services and tools for connecting on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

- Migrating Windows Server and Microsoft workloads to the cloud.
- Hosting enterprise websites and business applications.
- Running SQL databases and data-processing workloads.
- Supporting hybrid and multi-cloud environments.
- Backup, disaster recovery, and business continuity.
- Artificial intelligence, analytics, and application modernization.
